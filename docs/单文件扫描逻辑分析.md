# 单文件扫描逻辑分析

本文分析单个文件的扫描逻辑。

首先，整个工程的扫描主要封装在builder.py:full\_build()中，这里找到所有的文件用
\_render_file()做单文件的扫描，然后根据文件的扩展名，分别扫描rst和md文件

## render_rst()

这个处理用rst的文本去生成html内容，它的预处理是这样的：

1. 把docutil不认的role做一次预处理，好像这些role不存在一样
2. 调用docutils.core.publish_parts生成html
3. 把html body中的错误过滤掉（未来放到诊断窗口中）
4. 用正则表达式，把html body中的dtag提取出来
5. 其他后处理

所以这个算法是围绕着docutils来的，docutils怎么处理文本我们干涉不了，我们把处理分成了

* 前处理：修改.rst文本本身
* docutils处理
* 后处理：修改生成后的html

我们的所有行为可以改变的就是两处：前处理把我们私有rst语法改变后发给docutils，后
处理把docutils生成的html转化成我们期望的私有格式。
