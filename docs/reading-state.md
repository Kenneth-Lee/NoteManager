# 我的阅读 / 自上次访问设计

状态：已实现（Phase 2）
日期：2026-11-23
范围：项目首页的阅读面板 + 文档页的已读/星标按钮

## 1. 目标

- 首页显示「自上次访问以来」的修改；
- 显示待读、已读、星标和最近打开；
- 文档页可标记已读/未读、星标；
- 状态仅保存在浏览器，不引入账号、后端数据库或 LLM；
- 没有状态数据时完全回退，不影响现有页面。

## 2. 数据

构建时新增 `_index/activity.json`：

```json
{
  "version": 1,
  "docs": [
    {
      "path": "a/one.html",
      "title": "One",
      "mtime": 1795140000.0,
      "date": "2026-11-20"
    }
  ]
}
```

- mtime 来自源文件；
- 每次 `full_build` / `update_file` / `remove_file` 重建；
- 不包含正文。

## 3. 浏览器状态

localStorage key：

```text
nm-reading:<project_id>
```

project_id 由项目根路径的 sha1 生成，嵌入页面 `<body data-nm-project>`。

状态：

```json
{
  "read": {"a/one.html": 1795140000},
  "star": {"a/one.html": 1795140000},
  "recent": ["a/one.html", "b/two.html"],
  "lastVisit": 1795140000
}
```

- `read` / `star` 使用对象，方便忽略已删除路径；
- `recent` 最多 10 条；
- `lastVisit` 只在你打开项目首页时更新。

## 4. 首页面板

在统计信息下方显示「我的阅读」：

- **自上次访问以来**：源文件 mtime 晚于 lastVisit 的文档；
  - 第一次访问时显示「最近更新」而不是「自上次访问」；
  - 没有变化时显示「没有新的变化」。
- **待读**：未标记已读的文档数和最近几篇；
- **星标**：已星标文档；
- **最近打开**：文档页最近访问记录；
- 显示 `已读 X / N · 星标 K`。

首页渲染完成后更新 lastVisit，所以下一次打开首页会以这次访问为基线。

## 5. 文档页

在顶部操作区显示：

- `标记已读` / `已读 ✓`：点击可切换；
- `☆ 星标` / `★ 已星标`：点击可切换；
- 文档打开 2 秒后自动标记为已读，按钮可再标记为未读；
- 打开文档会写入 recent。

## 6. 降级

- 没有 `activity.json`：首页面板隐藏；
- `fetch` 失败：面板隐藏，正文和搜索不受影响；
- `localStorage` 不可用：状态功能静默失效；
- 直接通过 `file://` 打开时 fetch 可能被浏览器阻止，建议通过 NoteManager Web 访问。

## 7. 限制

- 状态按浏览器保存，不同浏览器/设备不共享；
- 项目根路径变化会导致 project_id 变化；
- lastVisit 以首页打开时间为基线，不跟踪单独文档页；
- 自动已读是 2 秒停留，不是严格阅读完成判定。

## 8. 测试

- 文档页包含阅读控制区、data-nm-page-path 和项目 id；
- localStorage/JS 逻辑通过浏览器手工测试；
