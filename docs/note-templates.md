# 新笔记模板

## 1. 目标

新建笔记时，如果存在模板，就使用模板内容初始化文件，而不是默认的标题/TODO 草稿。模板支持项目级和用户级两套，项目模板优先。

设计基线：`master` 分支，2026-11-27。

## 2. 模板位置

模板文件名固定为：

```text
template.md
template.rst
template.txt
```

按以下顺序查找：

1. 当前项目的 `.NoteManager/template.<ext>`
2. 用户配置目录的 `template.<ext>`（通常是 `~/.NoteManager/template.<ext>`）

模板扩展名必须与要创建的笔记扩展名一致。例如创建 `.rst` 笔记时不会使用 `template.md`。

项目模板适合某个知识库的固定格式；用户模板适合所有项目通用的个人习惯。

## 3. 模板变量

模板内容原样写入新文件，其中以下占位符会被替换：

| 占位符 | 替换值 |
|---|---|
| `{{filename}}` | 完整文件名，例如 `network.md` |
| `{{stem}}` | 不含扩展名的原始文件名，例如 `network` |
| `{{title}}` | 适合作为标题的文件名，`_`/`-` 转为空格 |
| `{{date}}` | 创建日期，`YYYY-MM-DD` |
| `{{year}}` | 创建年份，`YYYY` |
| `{{time}}` | 创建时间，`HH:MM:SS` |
| `{{datetime}}` | 创建日期时间，`YYYY-MM-DD HH:MM:SS` |
| `{{project}}` | 项目目录名 |
| `{{dir}}` | 新笔记所在目录相对项目根目录的路径；根目录为空 |
| `{{multi:字符}}` | 把字符重复标题的显示宽度次，如 `{{multi:=}}` 生成与标题等宽的 `====` |

`{{multi:*}}`、`{{multi:=}}`、`{{multi:-}}` 等可以用于 reST 标题下划线。重复次数按标题的显示宽度计算，CJK 字符按双宽度计算。

如果模板中没有占位符，内容原样使用。未知的 `{{...}}` 保持不变。

## 4. 回退规则

- 项目模板存在且可读 → 使用项目模板；
- 否则用户模板存在且可读 → 使用用户模板；
- 都不存在或读取失败 → 使用原来的默认内容；
- 模板存在但内容为空 → 创建空笔记，不再回退到默认内容。

## 5. 示例

项目 `.NoteManager/template.md`：

```markdown
# {{title}}

- 创建日期：{{date}}
- 所属项目：{{project}}
- 所在目录：{{dir}}

## 背景

## 结论

## 参考
```

新建 `sub/network.md` 后得到：

```markdown
# network

- 创建日期：2026-11-27
- 所属项目：my-notes
- 所在目录：sub

## 背景

## 结论

## 参考
```

reST 模板可以使用相同的变量：

```rst
{{title}}
{{multi:=}}

:创建日期: {{date}}

TODO
```

`{{multi:=}}` 会生成与标题显示宽度相同的 `=` 下划线，因此中文标题也不需要手工数长度。

## 6. 边界

- 不执行模板中的代码或命令；
- 不支持条件、循环、继承模板；
- `{{multi:...}}` 只按标题宽度重复字符，不解析 reST 结构；
- 不支持 `.markdown`/`.mdown` 模板，只支持 `.md`/`.rst`/`.txt`；
- 模板只影响新建笔记，不影响已有文件。
