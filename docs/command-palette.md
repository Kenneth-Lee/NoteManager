# 命令面板与保存的搜索视图

状态：已实现（Phase 3）
日期：2026-11-24
范围：所有 NoteManager 页面 + 项目首页快捷视图

## 1. 命令面板

在项目首页和文档页按 `Ctrl+K` / `Cmd+K` 打开：

- 输入关键词搜索文档/章节/标签/索引；
- 支持现有搜索前缀：`chapter:`、`label:`、`index:`、`dtag:`、`fname:`、`grep:`；
- 默认不显示 `grep:` 正文块，显式输入 `grep:` 才搜索；
- `↑` / `↓` 选择，`Enter` 打开，`Esc` 关闭；
- 输入为空时显示动作命令和已保存视图。

动作：

- 回到项目首页
- 返回控制台
- 复制当前页面链接

搜索输入非空时，额外显示：

- 保存查询为视图

## 2. 保存的搜索视图

- 在命令面板输入查询后选择「保存查询为视图」；
- 输入名称，保存到浏览器 localStorage；
- 首页「快捷视图」区域显示所有已保存视图；
- 点击视图用现有搜索侧边栏执行查询；
- 视图右侧 `×` 删除；
- 同名视图再次保存会覆盖查询。

localStorage key：

```text
nm-views:<project_id>
```

project_id 与阅读状态一致，由项目根路径生成。

## 3. 帮助与可发现性

- 侧边栏搜索框下方常驻提示：`Ctrl/⌘ K 命令面板 · 快捷键说明`；
- 点击「命令面板」直接打开面板；
- 点击「快捷键说明」打开快捷键帮助，列出：
  - `Ctrl/⌘ K` 打开/关闭命令面板
  - `↑` / `↓` 选择
  - `Enter` 打开选中项
  - `Esc` 关闭
  - `Ctrl/⌘+Alt+1/2/3` 切换渲染 / 源文件 / 诊断；`Ctrl/⌘+Alt+C` 是源文件的兼容快捷键
  - `Ctrl/⌘+Alt+S` 切换分屏（文档页）
  - `Ctrl/⌘+Alt+E` 外部编辑器打开当前源文件
  - `Alt+↑` / `Ctrl/⌘+Alt+U` 回到项目主页并展开当前目录
- 搜索框右侧的 `?` 搜索语法弹窗中也加入了快捷键列表；
- 命令面板空输入时提供「快捷键帮助」命令。

## 4. 实现

新增 `_static/nm-command.js`：

- 按 `window.NM_PREFIX` 定位 `_index/search_index.json`；
- 懒加载索引并在空闲时预取；
- 搜索逻辑与现有侧边栏搜索保持一致；
- 首页 `#nm-saved-views` 容器由脚本渲染；
- 保存/删除只改 localStorage，不触发构建。

现有搜索脚本暴露：

```js
window.nmRunSearch(query)
```

命令面板和快捷视图通过它把查询交给侧边栏搜索。

## 5. 限制

- 搜索视图保存在当前浏览器，不同浏览器/设备不共享；
- 项目根路径变化会导致 project_id 变化；
- 保存视图的查询语言仍是现有前缀/正则语法，没有新增
  `path:`、`modified:` 等过滤器；
- 直接 `file://` 打开时搜索索引 fetch 可能被浏览器阻止，命令面板搜索不可用，
  动作命令仍可工作；
- 没有服务端搜索历史。

## 6. 测试

- 全量构建包含 `nm-saved-views` 容器和 `nm-command.js`；
- 命令面板可打开、搜索、显示结果；
- 首页快捷视图可显示、删除；
- 搜索脚本暴露 `nmRunSearch`；
- 既有测试不回归。
