# 项目主页概览 / 径向目录关系图设计

状态：已实现（Phase 1，径向关系图版）
日期：2026-11-23
范围：`.NoteManager/html/index.html` 与 `topics.html` 的构建时概览

## 1. 背景

项目主页此前只有侧边栏目录树，正文基本为空。中间尝试过：

1. treemap：面积由文档数量决定，会把辅助目录放大，偏离用户的心理地图；
2. 横向/折叠目录卡片：空间利用率低，需要一层层展开或横向滚动。

最终改为：**从中心向外扩散的径向目录关系图**。目录节点是圆，圆直径表示文档数；
节点颜色/绿点表示重要性和近期活跃度；点击节点不复制文件列表，而是在左侧
目录树中展开对应位置。

## 2. 目标

1. 根节点在中心，目录按层级向外扩散，一次看到完整目录结构。
2. 用圆形直径表达目录文档数，节点位置和连线表达层级关系。
3. 目录名放在圆外，文档数放在圆内，避免每个节点都占一整块卡片。
4. 顶层重要目录高亮，近期修改用绿点标记；悬停可看日期/被引次数。
5. 点击目录节点时，在左侧侧边栏目录树中展开并高亮对应目录。
6. 主题与目录分开，只展示标签/索引词/章节/文档主题。
7. 保留“核心文档”和“最近更新”。
8. 完全离线、构建时生成、确定性；不依赖 LLM 或网络。
9. 增量更新（`update_file` / `remove_file`）后概览同步刷新。

## 3. 非目标（Phase 1）

- 不做真正的语义摘要/生成式总结。
- 不做个性化推荐（最近浏览、搜索历史）。
- 不做 TF-IDF/嵌入聚类。
- 不做 treemap 或力导向图；使用确定性的径向树布局。
- 不在主页面再放一份目录/文件列表；文件浏览统一由侧边栏承担。
- 不改变搜索索引和现有文档页。
- 不保证手机导出包包含新主题页（后续单独处理）。

## 4. 数据来源

全部来自现有构建产物：

- `_index/search_index.json`
  - `chapter`：章节标题、锚点
  - `dtag`：文档标签
  - `index`：RST `.. index::` 条目
  - `grep`：正文段落，用于主题摘录
- 渲染后 HTML 中的内部 `<a href>`：入链/核心文档
- 文档路径：目录树
- 源文件 mtime：最近更新、近期活跃度
- 文档标题：小工程/无结构工程的主题 fallback

## 5. 径向关系图

目录树转换为径向树：

- 根节点在画布中心；
- 子节点按叶子数量分配扇区角度，放在对应深度的圆环上；
- 叶子节点先分角度，父节点角度取子节点扇区中点；
- 连线从父圆边缘到子圆边缘；
- 绘制结束后计算节点圆和外围标签的**紧致包围盒**，用它作为 SVG 的
  `viewBox`，避免按整圆环画布留下大块无用边缘；
- SVG 默认宽度 100%，高度按包围盒比例自动计算；
- 图上方提供比例滑块（50%–300%）、“适应”和“重置”：
  - “适应”按容器宽度和 `80vh` 高度计算合适比例；
  - 手动比例可放大到 300%，容器内部滚动；
  - 比例保存在浏览器 `localStorage`；

节点圆形：

- 根节点固定半径 28px；
- 目录半径 `8 + 22 * sqrt(doc_count / max_doc_count)`，即**面积/直径随文档数增长**；
- 圆内显示文档数；
- 目录名放在圆外，按所在方向选择左/右对齐；
- 顶层前 3 个重要目录用 hot/warm 底色；
- 近期有修改的节点右上角显示绿色圆点；
- 完整名称、最近日期、被引次数放在 SVG `<title>` 提示中；
- 点击目录圆会在侧边栏中展开该目录。

布局限制：

- 圆环节点较多时自动增大半径，避免节点挤在一起；
- 极多/极深目录时图形会缩小，SVG 可滚动；Phase 2 可考虑缩放/拖拽。

## 6. 交互：下钻、返回与侧边栏联动

### 6.1 节点下钻

点击任意目录节点，都会同步左侧目录树；如果有子目录，还会把它作为新的根重新绘制关系图：

- 当前根节点显示在中心；
- 只展示该节点的子树；
- 图上方显示 `项目 / 目录 / 子目录` 面包屑；
- 「← 返回」回到上一个视图；
- 「⌂ 根」直接回到整个工程的根；
- 浏览器前进/后退同步（使用 `pushState` / `popstate`）；
- 点击当前根节点本身不会再次下钻，但会同步侧边栏到该目录；
- 叶子目录没有可展开的子树，点击时只打开侧边栏对应位置；
- `Shift`/`Alt` 点击任意节点只做侧边栏定位，不下钻。

### 6.2 侧边栏联动

主页面不再重复生成“目录文件”区域。侧边栏本身已经是完整的目录/文件树：

- 每个目录 `<details>` 使用稳定的 `nm-dir-<hash>` id；
- 主图节点 href 指向同一个 id；
- 点击节点执行 `nmRevealSidebarDir(id)`：
  1. 打开所有祖先 `<details>`；
  2. 切换到侧边栏“目录”视图；
  3. 滚动到该目录并短暂高亮；
- 文件仍由侧边栏目录树打开，避免主页面重复一片目录区域；
- 侧边栏目录树默认折叠，只显示一级目录。

无 JavaScript 时，锚点仍指向侧边栏对应目录；用户可以手动展开侧边栏。

## 7. 主题

目录已经承担结构导航，所以“主题”只使用非目录主题：

1. 显式 `dtag` 标签；
2. RST `.. index::` 索引词（至少两篇文档共享）；
3. 重复章节标题（过滤“介绍 / 小结 / 参考 / 其他”等通用标题）；
4. 根目录文档、小工程文档 fallback。

规则：

- 只有目录/标签/索引主题不足 8 个时，才加入重复章节主题；
- 文档数 ≤ 80 时，根目录文档作为主题；大工程根目录文档 ≥5 时合并为“根目录”；
- 单篇文档的索引词不进入主题；
- 主题 id 由名称哈希生成，锚点稳定；
- 同名主题合并。

展示：

- 主页最多显示 6 个主题卡片；
- “查看全部主题”进入 `topics.html`；
- `topics.html` 只列非目录主题，每个主题显示文档、章节和摘录。

## 8. 页面形态

```text
项目名
N 篇文档 · M 个章节 · K 个标签 · L 条内部链接

目录概览
  ┌──────────── 径向目录关系图（完整层级） ────────────┐
  │                    ○ 子目录                        │
  │                 ○ 目录                             │
  │          ○ 一级目录        ○ 一级目录               │
  │                    ● 项目                           │
  │          ○ 一级目录        ○ 一级目录               │
  └────────────────────────────────────────────────────┘
  [← 返回] [⌂ 根] 项目 / 目录 / 子目录  [侧栏定位]
  比例 [滑块] 80% [适应] [重置]

主题
  [标签/章节/文档主题卡片]
  查看全部主题 →

核心文档            最近更新
- ...               - ...
```

- 目录关系图是主视图；圆直径/颜色/绿点表达信息量、重要性和近期活跃度。
- 图按紧致包围盒渲染，默认适应容器；比例可手动放大/缩小。
- 点击图节点在左侧目录树展开，不在主页面重复文件列表。
- 左侧侧边栏目录树默认折叠，只显示一级目录；搜索仍然保留。

## 9. 构建接入

`overview.py`：

- `build_overview(...)`：主题、目录树、核心/最近数据；
- `_build_directory_tree(...)`：目录聚合和热度；
- `_radial_layout(...)`：径向树布局；
- `_render_directory_graph(...)`：服务端初始 SVG；
- `dir_node_id(...)`：主图与侧边栏共用的稳定目录 id；
- `renderer/assets/nm-overview.js`：客户端下钻、历史栈、面包屑、
  紧致包围盒重绘和比例控制；
- `render_landing_overview(...)`：主页正文；
- `render_topics_page(...)`：主题页；
- `build_and_write(...)`：写 `_index/overview.json` 和 `topics.html`。

接入：

- `full_build()`：索引与 dtag/ref 写完后生成概览，再生成首页；
- `update_file()`：重建索引后重新生成概览和首页；
- `remove_file()`：删除文件并重建索引后重新生成概览和首页；
- 概览生成失败只记录日志，不阻断构建，首页回退到原“NoteManager”标题；
- 空工程/删除最后文档时清理旧的 `topics.html` / `overview.json`；
- 旧工程首次增量构建时自动补齐新样式。

## 10. 测试

- 全量构建生成 `overview.json`、`topics.html`，主页含径向关系图、主题卡片、
  目录树和 `topics.html` 链接；
- 目录树聚合文档数、章节数、入链、热度；
- 径向图生成 SVG 圆形节点/连线，节点数据与侧边栏目录 id 一致；
- 客户端下钻、返回、根按钮和面包屑可用；
- 主题排除目录，只保留标签/索引/章节/文档；
- 侧边栏树默认不 `open`，且带稳定目录 id；
- 增量新增/删除文件后概览同步；
- 删除最后文档清理旧概览；
- 文档页/搜索/导出等既有测试不回归。

## 11. 已知限制

- 摘要为抽取式，不是生成式；短文档可能没有合适摘录。
- 主题质量依赖目录、标签、索引词和章节标题。
- 目录热度由内容量/近期活跃度计算，不代表用户个人兴趣。
- 径向布局在目录极多/极深时会缩小或需要滚动；当前提供比例滑块和“适应”，
  后续可再加拖拽/平移。
- 下钻只切换图的根，不改变侧边栏的当前目录；侧边栏定位需要点击「侧栏定位」
  或叶子节点。
- 文件浏览完全依赖侧边栏；侧边栏在手机隐藏时需要额外交互（后续处理）。
- 手机导出包暂未包含主题页。
