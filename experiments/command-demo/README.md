# Command palette / saved views demo

Screenshots of the third feature:

- `command-palette.png`: Ctrl/Cmd+K opened on the demo homepage;
- `command-search.png`: searching `架构` and showing a matching chapter + save action;
- `command-saved-views.png`: two saved views rendered under "快捷视图" on the homepage.

The demo was built from a small 3-document project and served over HTTP.
View data is stored in localStorage; the screenshots seed the values only to show
the layout.
