# File-tree creation/deletion demo

Screenshots of the P0 note lifecycle feature:

- `tree-actions.png`: directory `+` buttons and file delete `×` buttons;
- `create-note-dialog.png`: target-directory, filename, and format dialog;
- `delete-note-dialog.png`: delete impact (backlinks/images) and trash warning;
- `document-delete-button.png`: the delete entry on the document page itself.

The screenshots were taken from a static demo served at `/p/0/`; the delete
impact values in the dialog screenshot are stubbed for layout. Backend creation
and trash movement are covered by tests.
