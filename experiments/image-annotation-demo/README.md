# Image annotation demo

- `annotation-overlay.png`: rendered page with an `.ann.svg` overlay on an image;
- `annotation-editor.png`: first basic SVG annotation editor;
- `annotation-editor-v2.png`: selection, line style, width and text-size controls;
- `annotation-editor-fill.png`: fill color controls and existing sidecar loaded in the editor;
- `annotation-selected.png`: selected primitive with glow, bounding box, resize handle and property values;
- `annotation-multiselect.png`: Shift/Ctrl+A multi-selection with common properties;
- `image-zoom.png`: display-width preview and generated Markdown/reST snippets.

The demo uses a static page, so saving is not exercised by the screenshots.
Backend annotation saving is covered by tests.
