# Shortcut discoverability demo

Screenshots for the shortcut-help improvement:

- `shortcut-hint.png`: persistent `Ctrl/⌘ K 命令面板 · 快捷键说明` hint
  under the sidebar search box;
- `shortcut-help-modal.png`: the help dialog opened from the hint.

The hint and the command-palette button are visible without knowing any hotkey.
The existing `?` search-help popup also lists the command-palette shortcuts.
